# Источники вакансий для русскоязычных разработчиков в международных компаниях

Ниша: русскоязычные разработчики, ищущие удалённую работу в иностранных (не РФ/СНГ) компаниях
с возможностью общаться на русском внутри команды (RU-friendly работодатели).

Ранее найдено (не дублируется здесь): [iDagent — 150 компаний](https://idagent.pro/companies),
[Habr-сборник 200+ компаний](https://habr.com/ru/articles/1021472), [career.habr.com](https://career.habr.com),
Telegram `t.me/s/` как метод чтения, [Himalayas API](https://himalayas.app/api).

## 3. Другие краудсорс-списки компаний

Помимо iDagent и Habr-сборника (найдены ранее), самостоятельного независимого списка именно
"компании с русскоязычными командами на международном рынке" в ходе этого прохода не найдено.
Единственный кандидат — тот же **idagent.pro/job-sources**, но он про источники вакансий, не
про список компаний, и не верифицирован напрямую (403 на прямой запрос).

**Вывод:** это открытый пробел — стоит либо вручную открыть idagent.pro/job-sources в браузере
(без автоматического fetch), либо считать, что помимо iDagent/Habr других зрелых краудсорс-баз
компаний в этой нише сейчас нет — свободная ниша для дифференциации, не занятая ниша с конкурентом.

## Рекомендация для модуля агрегатора

Подключать: **Djinni** (структурированный API/страницы вакансий, фильтр по английскому — полезно
для нашей RU-friendly сегментации) + уже решённые Telegram-каналы, добавив **Remocate**
(@evacuatejobs) и **СЕТИ** (@it_vakansii_jobs) в список источников для `t.me/s/`-скрапинга.

Проверить вручную: idagent.pro/job-sources — если содержимое доступно живому пользователю в
браузере (403 похож на бот-защиту, не на отсутствие контента), может закрыть сразу оба вопроса
(источники вакансий + возможно источники компаний) одним найденным списком.

getmatch.ru — не приоритет, профиль не подтверждён как "международные компании", похоже больше
на RU-рынок.
